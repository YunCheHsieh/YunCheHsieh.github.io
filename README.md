# Yun-Che Hsieh — Personal Website

This static personal website is built for GitHub Pages. It presents selected work in applied physics, science education, system building, and GreenMind.

## Local preview

Run the following command from the project directory:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## GitHub Pages

No build tool is required. Configure the root of the `main` branch as the GitHub Pages publishing source.
